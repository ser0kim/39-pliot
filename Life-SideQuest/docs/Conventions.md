# 협업 컨벤션

커밋: `[태그] #이슈번호 - 작업내용`

브랜치: `태그/#이슈번호`

| 태그 | 용도 |
| --- | --- |
| feat | 새로운 기능 |
| style | UI 구현 |
| fix | 버그·오류 수정 |
| docs | 프로젝트 문서 |
| setting | 프로젝트 설정 |
| add | 에셋·라이브러리 추가 |
| refactor | 기존 코드 개선 |
| chore | 경미한 수정 |
| network | 네트워크 작업 |
| merge | 머지 |

PR 제목도 커밋 형식을 따른다. 머지 커밋은 `[merge] #이슈번호 - 작업내용`으로 작성한다. 머지 완료 후 원격·로컬 작업 브랜치를 삭제한다.
