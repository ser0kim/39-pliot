# 04 화면 설계서의 미정 정책에 대한 초기 구현값

아래는 확정된 기획이 아니라 동작 가능한 초기 구현을 위한 정책이다. 변경 지점은 Domain 유스케이스에 모은다.

- 이름: 앞뒤 공백 제거 후 Swift Character 기준 1~10자. 아이디: 영문·숫자·밑줄 1~30자, 로컬 식별자이며 서버 중복 검사 없음.
- 신규 모험가: Lv.1, 0 EXP, 완료 기록 없음. 화면 예시의 Lv.2·12개는 실제 사용자 데이터로 만들지 않는다.
- 레벨당 100 EXP를 초기 정책으로 사용하며 초과분은 이월한다. 전체 레벨표 확정 시 GrowthPolicy를 교체한다.
- 진행 의뢰는 한 개. 완료 사진 필수, 한마디 선택·최대 100자. 사진 자동 판정 없음.
- 재추첨은 횟수 제한 없이 가능하며 현재와 겹치지 않는 새 의뢰 3개를 무작위로 선택·저장한다. 완료·진행 의뢰와 최근 노출은 조합 키로 제한한다. 세부 정책은 QuestGeneration.md 참고.
- 장소: ‘어디서나’ 의뢰는 집·밖 모두에 포함. 시간: 10분·30분 경계 포함.
- 조건 닫기는 임시 선택 폐기. 초기화는 임시 조건만 해제. 적용 후 진행 의뢰 유지.
- 기록은 최신순. 도감 상단 개수는 전체 완료 수. 완료 번호는 1부터 순차 발급.
- 취소는 진행 의뢰와 초안만 폐기하며 기존 경험치와 완료 기록 보존.
- 완료 기록은 당시 이름·의뢰·보상·날짜·사진을 스냅샷으로 저장. 재열람은 보상을 지급하지 않는다.
- 칭호 초기 조건: 첫 완료, 총 5회 완료, 탐험 5회 완료. 대표 칭호 변경은 화면 설계에 없으므로 제공하지 않는다.
- 데이터는 이 기기의 Application Support에 원자적으로 저장. 저장 실패 시 이전 상태와 초안을 유지하고 오류 표시. 자동 초기화하지 않는다.
- S05의 도감 버튼은 새 기록의 S07 상세로 이동하며, 뒤로가기는 S06으로 이동한다.

## 상세 화면 내비게이션
- Figma 04 화면 설계서: S02·S02-A·S06·S08은 탭바 표시, S03 의뢰 상세·S04 기록 작성·S05 발급 완료·S07 과거 기록 상세는 숨김. 루트 위의 조건·이름 변경 팝업은 기존 화면 유지.
- 선택 탭의 NavigationStack 경로가 비었을 때만 MainTabView가 탭바와 하단 공간을 표시한다. 뒤로가기·수락 후 복귀 시 자동 복원하며 다른 탭의 이전 경로는 영향을 주지 않는다.
- 상세 3개 화면은 시스템 상단 바와 뒤로가기를 숨기고 Figma 원본 24pt 화살표·17pt 왼쪽 제목을 공통 사용. 기록 작성의 뒤로가기는 초안 저장 성공 후 이동한다.
